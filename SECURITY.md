# Segurança

Encontrou uma falha de segurança (por exemplo, algo que exponha o token ou dados de outros usuários)?
**Não abra uma issue pública.** Use o botão **Report a vulnerability** na aba
[Security](../../security/advisories/new) deste repositório; a mensagem fica visível só para os mantenedores.

Se o seu token pode ter vazado, gere outro na página Configurar do site: o antigo deixa de funcionar na hora.
